# ML Property Price Prediction

##  Project Overview

This project focuses on predicting property prices using Machine Learning techniques. The model analyzes various housing-related features to understand their relationship with property prices and generate accurate price predictions.

##  Problem Statement

Property prices depend on several factors such as location, population, income, and other housing-related characteristics. The objective of this project is to build Machine Learning models that can predict the median property value based on these features.

##  Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Machine Learning Models

The project uses regression techniques including:

* Simple Linear Regression
* Multiple Linear Regression

These models are trained and evaluated to understand their performance in predicting property prices.

##  Project Workflow

1. Load the dataset
2. Understand the dataset
3. Perform data cleaning and preprocessing
4. Conduct Exploratory Data Analysis (EDA)
5. Select relevant features
6. Split the data into training and testing sets
7. Build regression models
8. Evaluate model performance
9. Predict property prices

## Model Evaluation

The models are evaluated using regression metrics such as:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score
